# TP Alineamientos Secuenciales

Trabajo práctico de Bioinformática: búsquedas BLAST (remoto NCBI + archivos web) y análisis de resultados.

- `secuencia.fasta`: secuencia problema (desafío VII, prión, 133 aa).
- `blast_vii_remote.py`: script de evidencia — corrida BLASTp remota vs nr (`EXPECT=100`, `HITLIST_SIZE=20000`).
- `resultados/`: TSVs (`blast_vii.tsv`, `blast_viii_mitad.tsv`, `blast_viii_cuarto.tsv`, `blast_ix.tsv`, `blast_x.tsv`), filtrados y figuras.
- `informe_desafio_VII.md`, `informe_desafio_VIII.md`, `informe_desafio_IX.md`, `informe_desafio_X.md`: informes.
- `CXJR2NNZ014-Alignment desafio iX .txt`: alineamiento web original del desafío IX (LpxA, 262 aa).
