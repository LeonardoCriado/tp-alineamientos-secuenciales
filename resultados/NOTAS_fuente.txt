## Fuente del desafío VII

La tabla `blast_vii.tsv` se armó a partir del archivo de alineamiento web de NCBI `CV1UE1Z8014-Alignment(1).txt` y de una descarga CSV de la API para el mismo RID. El archivo web corresponde a BLASTP contra nr, con un query de 133 aminoácidos.

## Archivos y procesamiento

- `blast_vii.tsv`: tabla tomada de «Sequences producing significant alignments» (1927 hits). Se pasó de ancho fijo a TSV, sin filtrar ni reordenar los valores.
- `blast_vii.csv_raw.csv`: descarga tabular cruda de la API para el mismo RID (2618 líneas HSP, sin descripciones). Las descripciones de `blast_vii.tsv` se tomaron de la tabla web del mismo RID.
- Columnas de `blast_vii.tsv`: accession, descripción, nombre científico, nombre común, taxid, max score, total score, cobertura del query, E-value, identidad y longitud de la secuencia.
- `blast_vii_filtrado_e100_cov70.tsv`: resultado de aplicar E-value ≤ 100 y cobertura ≥ 70% a `blast_vii.tsv`. Se conservaron los 1927 hits (E-value máximo 84; cobertura mínima 70%).

## Limitaciones

El archivo web no muestra los parámetros EXPECT=100 ni HITLIST_SIZE=20000 en su encabezado, así que no permite comprobarlos para esa corrida. El script guardó una corrida propia con esos parámetros bajo RID CUZ2AG6F016, pero seguía en estado WAITING después de más de 16 horas.

La tabla web contiene 1927 hits y el CSV de la API 2618 líneas HSP, no 20000 hits. La respuesta web/API puede limitar la cantidad de descripciones y alineamientos que devuelve. No se completaron los registros faltantes de forma artificial. El CSV de la API tampoco incluye descripciones; por eso se usó la tabla web del mismo RID para agregar esa columna, sin modificar los valores numéricos.
